## how our ordering app works 

every order is added up by our app. We use the `total` variable to keep track of price:
```
let total = 0;
total = total + 8;

if (total >10)  {
  console.log("you get a free cookie!");
} else {
  console.log("added $2 more for a free cookie!");
}
```
